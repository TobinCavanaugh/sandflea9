# sandfleaOS
sandfleaOS is a UEFI x64 operating system built with a pragmatic and security first approach.
sandfleaOS is composed of primarily C code and x86_64 assembly, programs for sandfleaOS can be written in any language and compiled to WASM and executed.
- Executables are cross platform WASM bytecode
- IDE support (hard drive IO)
- EXT2 filesystem support (open, read, and close files)
- Processes with virtualized memory
- Kernel multitasking
- Keyboard input
- PCI device discovery
- 2D graphics support
- Text rendering via SSFN



### Philosophy
sandfleaOS has no interest in parity with existing operating systems or standards.
Libraries and standards used are used for their convenience or their genuine quality in solving a problem sandfleaOS faces.
